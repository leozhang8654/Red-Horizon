# Red Horizon（一号游戏）

一款用 **Godot 4.6** 开发的竖版飞机射击游戏（弹幕过关类）。这是作者的第一个游戏项目，从零开始学习游戏开发，记录在这里。

> 引擎：Godot 4.6 ｜ 平台：macOS ｜ 分辨率：1152 × 648

---

## 🎮 玩法介绍

你驾驶一架战机，从上往下迎击一波波敌人。靠灵活走位躲子弹、自动开火清场，撑到最后拿高分。

### 操作

| 操作 | 按键 |
| --- | --- |
| 移动 | 方向键 或 `W` `A` `S` `D` |
| 闪避翻滚 | `空格` |
| 暂停 / 继续 | `ESC` |
| 游戏结束后重开 | `空格` |

- **主炮 / 副炮自动开火**，你只管走位和闪避。
- 受伤后有短暂**无敌时间**，机身受击会闪烁提示。
- 翻滚时机身会做出**侧倾 / Roll 动画**。
- 按 `ESC` 暂停后，菜单里有**总音量滑条**，可调节并自动记住设置。

### 敌人波次

1. **第一波 · 杂兵（Dust Skimmer）**——V 字编队进场、空中悬浮、三炮口齐射。
2. **第二波 · 精英（Side Reaper）**——更硬更凶的精英敌机，同时场地里会出现**机械臂电锯**这种危险障碍。
3. **第三波 · Boss（MANTIS-LUX 巨型母舰）**——从顶部压入登场，分两阶段击破：
   - **第一阶段**：母舰主体打不动，只能逐个打爆**四个炮台**（各有血量）。招式是**环形弹幕** + **四炮台机枪**。
   - **第二阶段**：四炮台全爆后主体暴露，开始掉血。招式升级为**环形弹幕** + **中央横扫激光**。
   - 主体血量打光 → 大爆炸、过关。

清光当前一波才会进入下一波。

## 🕹️ 怎么运行

1. 安装 [Godot 4.6](https://godotengine.org/)（标准版即可，不需要 .NET 版本）。
2. 用 Godot 打开本项目文件夹（选中 `project.godot`）。
3. 按 **F5** 或编辑器左上角的 **▶** 运行主游戏。

---

## 🛠️ 开发者作弊（调试用）

游戏中按 **ESC** 暂停 → 在密码框输入 `123456` → 出现"波数跳跃"输入框 → 输入波数即可跳转：

- 输入 `1` → 跳到第一波（杂兵编队）
- 输入 `2` → 跳到第二波（Side Reaper + 机械臂）
- 输入 `3` → 跳到第三波（Boss 母舰）

## 📂 项目结构

| 文件 | 作用 |
| --- | --- |
| `main.tscn` | 主场景：背景、玩家、敌机生成器、HUD、结算画面、暂停菜单、震动相机 |
| `player.gd` | 玩家飞机：移动、机身侧倾、自动开火、血量与无敌、闪避翻滚 |
| `wave_spawner.gd` | 波次管理：第一波 → 清光后第二波 |
| `dust skimmer.gd` / `enemy.tscn` | 第一波小兵 |
| `side_reaper.gd` / `side_reaper.tscn` | 第二波精英敌机 |
| `mech_arm.gd` / `mech_arm.tscn` | 第二波机械臂电锯（场地危险物）|
| `boss.gd` / `boss.tscn` | 第三波 Boss（MANTIS-LUX 母舰）：登场、分阶段、三种招式 |
| `boss_bullet.gd` / `boss_bullet.tscn` | Boss 核心子弹（环形弹幕）|
| `boss_turret_bullet.tscn` | Boss 炮台机枪子弹 |
| `player bullet.gd` / `bullet.tscn` | 玩家主炮子弹 |
| `副炮子弹.tscn` | 玩家副炮子弹 |
| `enemy_bullet.gd` | 敌方子弹 |
| `explosion.gd` / `explosion.tscn` | 通用爆炸动画 |
| `hud.gd` | HUD：顶部分数 + 左下角爱心血条 |
| `game_over.gd` | 游戏结束画面 |
| `pause.gd` | 暂停菜单（含开发者作弊）|
| `camera_shake.gd` | 屏幕震动 |
| `background.gd` / `scroller.gd` | 滚动背景与循环滚动物体 |
